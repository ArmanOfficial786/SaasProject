## FIX APPLIED - Agent SaveChanges Issue

### Problem
When creating a company, the agent SaveChanges was failing because:
- Agent was not explicitly inserted into the repository
- Only added to the company's collection via `company.AddAgent(agent)`
- EF Core wasn't properly tracking the agent entity

### Solution
**File**: `Src/UserManagement/UserManagement.Application/Commands/CompanyCommands/CreateCompany/CreateCompanyCommandHandler.cs`

Changed from:
```csharp
company.AddAgent(agent);
await _unitOfWork.SaveChangesAsync(cancellationToken);
```

To:
```csharp
// Insert agent into repository to ensure it's tracked by EF Core
var agentRepo = _unitOfWork.Repository<Agent>();
agentRepo.Insert(agent);
company.AddAgent(agent);
await _unitOfWork.SaveChangesAsync(cancellationToken);
```

### What This Does
1. Explicitly inserts the agent into the Agents repository
2. Ensures EF Core tracks the agent as a new entity
3. Prevents constraint violations on CompanyId foreign key
4. Agent now properly saves with CompanyId populated
