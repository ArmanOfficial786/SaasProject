## ✅ AUTOMAPPER MAPPING EXCEPTION - FIXED

### **The Problem**
You were getting:
```
AutoMapper.AutoMapperMappingException: Missing type map configuration or unsupported mapping.
```

**Why?** 
The handler tries to map `Company` entity back to `CompanyCreateViewModel` for the response:
```csharp
return Response<CompanyCreateViewModel>.SuccessResponse(
    _mapper.Map<CompanyCreateViewModel>(company),  // ← Mapping Company → CompanyCreateViewModel
    "Company created successfully");
```

But only the reverse mapping existed (CompanyCreateViewModel → Company).

### **The Solution**
Added the missing reverse mapping in `CompanyViewModel.cs`:

**Before:**
```csharp
public class Mapping : Profile
{
    public Mapping()
    {
        // Map for creating company (INPUT)
        CreateMap<CompanyCreateViewModel, Company>();
    }
}
```

**After:**
```csharp
public class Mapping : Profile
{
    public Mapping()
    {
        // Map for creating company (INPUT)
        CreateMap<CompanyCreateViewModel, Company>();
        // Map for response (OUTPUT) ← ADDED THIS
        CreateMap<Company, CompanyCreateViewModel>();
    }
}
```

### **What This Does**
Now AutoMapper can:
1. ✅ Convert incoming `CompanyCreateViewModel` → `Company` (for database save)
2. ✅ Convert created `Company` → `CompanyCreateViewModel` (for API response)
